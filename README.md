# IT 機房設備管理

現代簡約風、響應式（RWD）的單一檔案網站，`index.html` 內含全部 HTML、CSS 與 JavaScript。

欄位：設備名稱、設備描述、類型（實體／虛擬）、作業系統、IP 位址、負責人、備註

功能：
- 搜尋與類型篩選，統計總數、實體、虛擬、有 IP 位址數量
- 點表頭排序：設備名稱、類型、作業系統、IP 位址、負責人可升序／降序切換（IP 依每段數字排序，空白值排最後），工具列亦有排序欄位與升降序切換
- 新增、編輯、刪除、清空全部設備，資料存在瀏覽器 localStorage；舊資料開啟時會自動移除已取消的類別、品牌型號欄位
- 匯出全部或目前篩選結果為 CSV（含 BOM，Excel 開啟中文不亂碼）
- 由 CSV 匯入：自動偵測 UTF-8／Big5 編碼與逗號／Tab 分隔，欄位順序與匯出相同（設備名稱、設備描述、類型、作業系統、IP 位址、負責人、備註；舊匯出檔若無設備描述欄位，該欄留空，其餘欄位按表頭對應）；舊匯出檔若含類別、品牌型號欄位，匯入時會按表頭對應並忽略該兩欄；類型 VM 轉虛擬、SERVER／PC 轉實體；頁面另有「下載匯入範本」按鈕

開啟方式：直接用瀏覽器開啟 `index.html`，或透過 GitHub Pages 線上使用。
