# IT 機房設備管理

現代簡約風、響應式（RWD）的單一檔案網站，`index.html` 內含全部 HTML、CSS 與 JavaScript。

欄位：設備名稱、類別、類型（實體／虛擬）、作業系統、品牌型號、IP 位址、負責人、備註

功能：
- 伺服器、網路設備、儲存設備、其他等分類（電源與空調已取消，既有項目自動轉為其他）
- 搜尋、類別與類型篩選，統計總數、實體、虛擬、伺服器數量
- 新增、編輯、刪除、清空全部設備，資料存在瀏覽器 localStorage
- 匯出全部或目前篩選結果為 CSV（含 BOM，Excel 開啟中文不亂碼）
- 由 CSV 匯入：自動偵測 UTF-8／Big5 編碼與逗號／Tab 分隔，欄位順序與匯出相同，匯入的資料會附加到現有清單，不會覆蓋；類型 VM 轉虛擬、SERVER／PC 轉實體；頁面另有「下載匯入範本」按鈕

開啟方式：直接用瀏覽器開啟 `index.html`，或透過 GitHub Pages 線上使用。
